# note 作成部隊（ちゃそまる用 note 専用作業場）

このフォルダは、ちゃそまる（@kabu_stock_chaso）の **note 記事** を制作するための専用作業場です。
Instagram 制作部隊（親フォルダ）とは成果物を分け、ブランド・コンプラ・キャラ設定は親フォルダのものを共有します。
**Claude Code はこのフォルダ（`note作成部隊/`）を開いて使ってください。** そうすると下記の note 専用メンバー・スキルが読み込まれます。

## 必ず最初に読むもの

- `../brand/brand-guide.md` — アカウントのコンセプト、ターゲット、トーン（Instagram と共通）
- `../brand/compliance.md` — 金融系発信の法令・表現ルール（**全メンバー必読・最優先**）
- `brand/note-guide.md` — note 独自のルール（記事の型、文字数、見出し画像、有料記事の注意）
- `brand/note-specs.md` — note の仕様（見出し画像サイズ、タグ、マガジンなど）
- `../brand/characters/` — 発信者キャラクター図鑑（Instagram と共通。新キャラもここに登録）

## 部隊メンバー（`.claude/agents/`）

| メンバー | 役割 |
|---|---|
| `note-strategist` | ネタ出し、月間の記事計画、記事ブリーフ（企画書）作成 |
| `note-researcher` | トレンド調査（YouTube・X・ネット検索で伸びている発信と理由）と、制度・数字の出典付きファクトシート作成 |
| `note-writer` | 記事の構成（見出し）と本文の執筆 |
| `note-editor` | 推敲、タイトル案、リード文、タグ、Instagram への導線 |
| `note-designer` | 見出し画像・記事内図解の作成（Canva）またはデザイン指示書 |
| `note-compliance-reviewer` | 法令・表現チェック（公開前の最終関門） |

## 制作フロー（スキル）

- `/plan-notes` — 1か月分の note 記事計画を作る
- `/create-note <テーマ>` — note 記事を一式作る（企画→調査→執筆→推敲→画像→コンプラ）

## 編集長（メイン Claude）のルール

1. 成果物は `content/` 以下に保存する（構成は `README.md` 参照）。テンプレートは `templates/`。
2. 数字・制度に触れる記事は必ず `note-researcher` を通し、出典を残す。
3. **公開前に必ず `note-compliance-reviewer` を通す。** 判定が「NG」なら修正して再レビュー。
4. note への投稿・Canva デザインの公開など、外部に出る操作はユーザーの明示的な確認を取ってから行う。
5. 発信者キャラクターは記事ごとにユーザーが指定する。指定がなければ図鑑から選んでもらう。未登録のキャラは `../brand/characters/` に登録してから制作する。
6. 個別銘柄の売買推奨、「必ず儲かる」等の断定表現は、どのメンバーの出力であっても採用しない。
7. **有料記事・メンバーシップ**は投資助言と誤解されやすいため、企画段階でユーザーに確認し、コンプラレビューを特に厳しく行う。
8. Instagram の既存投稿（`../content/`）を元ネタにして深掘り記事にしてよい。その場合はブリーフに元投稿のパスを書く。
