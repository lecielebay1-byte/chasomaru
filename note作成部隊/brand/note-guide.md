# note ガイド

> Instagram 用の `../brand/brand-guide.md` を土台に、note ならではのルールをまとめたものです。`【要確認】` は推定なので、違っていたら書き換えてください。

## note の役割（Instagram との違い）

| | Instagram | note |
|---|---|---|
| 役割 | 入口。流し見で「しくみ」を1つ知ってもらう | 深掘り。保存して読み返せる「教科書」 |
| 分量 | 1スライド60字 | 1記事 3,000〜6,000字が目安 |
| 読まれ方 | スマホで数秒 | スマホで5〜10分、検索・まとめ読み |
| 導線 | プロフィールのリンクから note へ | 記事末尾から Instagram フォローへ |

- 1記事＝1テーマ。Instagram 投稿1本を「なぜ？」「具体例」「よくある勘違い」で3倍に膨らませるイメージ
- 発信の柱・比率は `../brand/brand-guide.md` と同じ

## 記事の型

1. **タイトル**: 誰向け＋何がわかるか（30〜40字）。煽らない
2. **リード文**（200字以内）: 悩みへの共感 → この記事でわかること（箇条書き3つ）
3. **目次**（note の目次機能をオンにする）
4. **本文**: 見出し（大見出し `##` 3〜5個、必要なら小見出し `###`）
   - 各見出しの冒頭に結論 → 理由 → 具体例（架空の例を優先）
   - 図解を入れる場所は `【図解: 〜】` と指示を書く
   - キャラの吹き出し・ひとことコメントで区切って読みやすく（口調はキャラの `profile.md` に従う）
5. **まとめ**: 要点3つ＋次に読むとよい記事／Instagram 投稿
6. **CTA**: スキ・フォロー・Instagram（@kabu_stock_chaso）への誘導
7. **免責の一文**（必須、`../brand/compliance.md` の3章）

## 文章ルール

- です・ます調。一文は60字以内を目安に、1段落3行まで
- 専門用語は初出で必ず言い換え、太字にする
- 数字は `fact-sheet.md` にあるものだけ。時点と出典を本文中または記事末尾に書く
- 「爆益」「今すぐ」「知らないと損」などの煽りは使わない

## 有料記事・メンバーシップの注意【重要】

- 有料で「どの銘柄を、いつ売買するか」に関わる情報を提供すると、投資助言・代理業の登録が必要になるおそれがある
- 有料にするなら「しくみの解説」「学習ノート」「テンプレート」など一般的な学習コンテンツに限定する
- 有料部分にも無料部分と同じコンプラルールを適用。有料化前にユーザー確認必須、収益化を本格化する前に専門家へ相談する

## 見出し画像

- Instagram と同じ世界観（手描き水彩風・クリーム色の紙・ちゃそまるの書斎）
- タイトルを短く（15字前後）大きく入れ、キャラを右下などに配置
- 色・フォントは `../brand/brand-guide.md` のデザインルールに従う
