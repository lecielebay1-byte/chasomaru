# キャラクター図鑑

投稿ごとに発信者キャラクターを指定し、新しいキャラはここにストックしていきます。
新規登録は `/add-character`、または制作中に新しいキャラを指定すると編集長が自動で登録します。

## ルール

- 1キャラ＝1フォルダ: `brand/characters/<id>/profile.md` と `images/`
- `<id>` は英小文字とハイフン（例: `chasomaru`, `usagi-sensei`）
- 投稿の `brief.md` に使うキャラの ID を必ず書く
- 投稿で使ったら、上の表の「登場回数」を +1 し、`profile.md` の「登場した投稿」に追記する
- 見た目・口調を変えたくなったら `profile.md` を更新し、変更履歴に残す（過去投稿との統一感に注意）
- 掛け合い（2キャラ以上）の投稿もOK。その場合は全員の ID を書く
