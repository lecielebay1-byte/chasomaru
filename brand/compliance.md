# 金融系発信のコンプライアンスルール

投資情報の発信は法令違反やトラブルにつながりやすい分野です。部隊全員がこのルールを守り、`compliance-reviewer` が公開前に必ずチェックします。
※このファイルは一般的な注意点のまとめであり、法的助言ではありません。収益化（有料サービス、案件獲得）を始める際は専門家に確認してください。

## 1. 絶対NG（見つけたら即修正）

| NG | 理由 | 言い換え例 |
|---|---|---|
| 個別銘柄・個別ファンドの売買推奨（「〇〇株は今が買い」「このファンドを買え」） | 投資助言・代理業の登録なしに行うと金融商品取引法違反のおそれ | 「選ぶときのチェックポイント」「〇〇という種類の商品がある」と一般論にする |
| 売買タイミングの指示（「今週中に売って」「下がったら買い増し」） | 同上 | 「時期を読むのはプロでも難しい」「積立ならタイミングを分散できる」 |
| 断定的判断（「必ず儲かる」「絶対に増える」「損しない」「元本保証」） | 断定的判断の提供・誤認を招く | 「〜の可能性がある」「過去の実績では」「将来の成果を保証するものではありません」 |
| 誇大な成果表示（「1年で資産10倍」「放置で月10万」） | 誇大広告・景品表示法のおそれ | 根拠のある試算に限定し、前提条件を明記 |
| PR 表記なしの広告・アフィリエイト（証券口座の紹介など） | ステルスマーケティング規制（景品表示法） | 冒頭・画像内・キャプションに「PR」「広告」を明記 |
| DM・LINE・外部グループへの勧誘、「無料で銘柄教えます」 | SNS 型投資詐欺と同じ手口で信用を失う。詐欺に誤認される | 情報提供はアカウント上で完結させる |
| 実在人物・企業・金融機関になりすました表現やロゴの無断使用 | 権利侵害・なりすまし | 自作の図解を使う |

## 2. 要注意（根拠・注記があれば可）

- **数字・利回り・シミュレーション**: 前提（年利、期間、手数料・税金の扱い）を必ず書く。「年利5%で計算した場合の試算」など
- **過去のリターン**: 「過去の実績であり、将来を保証するものではありません」を添える
- **制度の数字（NISA の枠・iDeCo の掛金上限・税率など）**: 改正が多い。`researcher` が金融庁・国税庁など一次情報で最新を確認し、出典を残す
- **しくみ説明での企業名・銘柄名の例示**（株式投資アカウントなので出やすい）: できるだけ「A社」「架空のちゃそまる商事」など架空の例を使う。実在企業を出す場合は事実の説明にとどめ、「買い時」「おすすめ」「注目銘柄」と読める表現・株価予想をしない
- **チャート・テクニカル指標の解説**: 「このサインが出たら買い」ではなく「こういう見方がある」「必ず当たるものではない」と書く
- **特定の金融機関・証券会社名**: 比較・紹介する場合は客観的な事実のみ。広告なら PR 表記
- **自分の運用実績の公開**: 可。ただし「真似すれば同じ結果」と読める表現は避ける
- **手数料・コストの話**: 具体名を出すなら最新の数字を確認

## 3. 毎投稿の必須要素

- 最終スライドまたはキャプション末尾に免責の一文
  - 例:「※本投稿は情報提供を目的としたもので、特定の金融商品の購入をすすめるものではありません。投資は自己判断でお願いします。」
- 数字を使った場合は「〇年〇月時点」と出典
- 広告・案件の場合は「PR」表記

## 4. レビュー判定の基準

- **OK**: そのまま公開可
- **要修正**: 「2. 要注意」に注記漏れなど。修正案どおり直せば公開可
- **NG**: 「1. 絶対NG」に該当。修正後に再レビュー必須
