# 週間投稿計画を作る

指定: $ARGUMENTS

1. `content/reports/` に最新の分析レポートがあるか確認する。直近2週間以内のものがなく、過去投稿が5本以上あれば、先に `analytics-analyst` に振り返りを依頼する
2. `content-strategist` に週間計画を依頼する
   - 本数の指定がなければ「画像投稿3本・リール2本」
   - 季節性・直近の制度改正・分析レポートの提案を反映
   - 出力: `content/ideas/YYYY-Www.md`
3. 制度・数字を扱う企画が多い場合は、`researcher` に「その週の企画で前提となる制度の最新状況」を軽く確認させ、古い情報で企画していないかチェックする
4. ユーザーに計画を表で提示する（日付 / 形式 / テーマ / ピラー / フック案）
5. ユーザーの OK が出たら、各企画を `/create-post` または `/create-reel` で制作できることを伝える
