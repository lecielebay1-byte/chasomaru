# キャラクターを登録する

指定: $ARGUMENTS

1. `brand/characters/README.md` を読み、同じ・似たキャラが登録済みでないか確認する。登録済みなら「更新」として扱う
2. ユーザーの説明と貼られた画像から `brand/characters/_template.md` の項目を埋める
   - 画像がある場合: 見た目（色・服装・小道具・ポーズ）を画像から具体的に書き起こし、画像を `brand/characters/<id>/images/` に保存する
   - 説明だけの場合: 書かれていない項目は `brand/brand-guide.md` のトーンに合わせて案を出し、【要確認】を付ける
3. `brand/characters/<id>/profile.md` を作成（更新なら変更履歴に追記）
4. `brand/characters/README.md` の表に1行追加（更新なら該当行を修正）
5. ユーザーに、登録内容の要点（見た目・話し方・得意テーマ）と【要確認】の項目を短く伝える

キャラの ID は英小文字とハイフンで、ユーザーが指定しなければ名前から決める。
